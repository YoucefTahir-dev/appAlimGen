# Internationalisation

L'application utilise le système i18n officiel de Django.

## Langues activées

- Français : `fr` — langue par défaut
- Arabe : `ar` — interface en RTL

## Ajouter une langue

1. Ajouter la langue dans `LANGUAGES` dans `gestio_stock/settings.py`.
2. Créer le catalogue :

   ```bash
   django-admin makemessages -l <code_langue>
   ```

3. Traduire le fichier `locale/<code_langue>/LC_MESSAGES/django.po`.
4. Compiler les traductions :

   ```bash
   django-admin compilemessages
   ```

5. Vérifier l'affichage desktop, tablette et mobile.

Sur Windows sans GNU gettext, utiliser :

```bash
python scripts/compile_translations.py
```
